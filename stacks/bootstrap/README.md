# Bootstrap stack

This stack has one job: create the GCS bucket that the `valheim` stack uses
as its Terraform remote-state backend. It's a classic chicken-and-egg
problem - the backend bucket can't be managed by the same state it stores -
so this stack applies once, by hand, with local state, and is rarely
touched again.

## Usage

```sh
cd stacks/bootstrap
terraform init
terraform apply -var="project_id=<your-gcp-project-id>"
```

Note the `state_bucket_name` output, then set it as the `bucket` value in
`stacks/valheim/backend.tf` (generated by Terramate from
`stacks/valheim/backend.tm.hcl` - update the global there, not the
generated file directly) before running `terraform init` in `stacks/valheim`.
